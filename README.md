Программа для управления задачами на C++ с сохранением данных в файл.

Возможности: добавление, редактирование, удаление задач. Можно отметить задачу как выполненную и показать только невыполненные.

Данные сохраняются в текстовый файл и загружаются при запуске программы.

Сборка выполняется через CMake, что позволяет собирать проект на разных платформах без изменения файлов.
